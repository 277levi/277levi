## Featured

### [evilhunt](https://github.com/277levi/evilhunt)
Zero-dependency web security scanner. Single file, pure Python stdlib. Detects CORS misconfig, missing headers, cookie flags, open redirects, dangerous verbs - and exports an interactive HTML PoC for confirmed CORS findings.

    curl -O https://raw.githubusercontent.com/277levi/evilhunt/main/evilhunt.py
    chmod +x evilhunt.py && ./evilhunt.py https://target.example.com
